# 🗡️ RPG Dungeon (2024)

You start choosing your own character (avatar selection) and choosing your own habilities. This is important as each caracter has different habilities.
Once you have chosen your character, you will appear at the dungeon. 
Move using WASD, each time you move there is a small chance a monster will appear.
You will be given coins if you defeat it. 

* **Shop (T) -> disappears once you enter.
* **Coins (O)
* **Boss Fight (F)

YOU NEED TO IMPROVE YOUR CHARACTER WEAPONS BEFORE FIGHTING THE BOSS

### 🎮 Controls

* **W A S D** → Move through the dungeon
* **I** → Open inventory
* **1 / 2** → Combat options, shop and inventory

**Explore through the dungeon. Collect coins. Equip better weapons. Survive. Defeat the BOSS.**
